# 🅿️ Smart Parking System

A modern web-based Smart Parking System for Pune malls.

## Features
- User login & registration
- Real-time slot booking
- UPI / QR / Card payment
- Booking cancellation & refunds
- Admin dashboard with slot management

## Malls Covered
- Phoenix Mall of the Millennium
- ElPro City Square Mall
- Phoenix Market City Pune
- Amanora Mall

## Tech Used
- HTML, CSS, JavaScript
- LocalStorage for data
- No backend required
